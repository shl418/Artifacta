# Artifacta v1.0.0

Artifacta v1.0.0 is the first stable open-source release of the protocol and hosting platform for AI-generated data applications.

## Highlights

- Host single-file HTML dashboards or ZIP bundles with static assets and bundled CSV/JSON data.
- Keep untrusted dashboard previews sandboxed while supporting private, team, and public visibility.
- Edit visible dashboard text in the browser with version history, rollback, drafts, and concurrent-edit merging.
- Publish and automate projects with the public `@artifacta/cli`, REST API, and `artifacta-publisher` skill.
- Use project-level bundle sync scripts for manually triggered data updates.

## Compatibility and deployment

- Requires Node.js 24.16.0 and pnpm 11.1.3 for development and self-hosting.
- The manifest v1 contract is documented in `docs/protocol/manifest-v1.md`.
- `@artifacta/cli@1.0.0` is the supported public CLI release.

## Important boundaries

- PostgreSQL metadata storage is currently a single JSONB-blob proof of concept; use JSON or SQLite for evaluation and treat relational PostgreSQL support as future work.
- Dataset-level URL, COS/S3, and Presto sync connectors are not available. Dynamic updates use manually triggered bundle sync scripts.
- Uploaded dashboards are untrusted content and must continue to be served through the sandboxed preview path.

## Upgrade notes

ZIP publishing uses upload sessions. Data files and bindings for ZIP dashboards belong in the bundle and are described by bundled `artifacta.json` or server-side auto-discovery.
